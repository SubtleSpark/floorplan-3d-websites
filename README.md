# 双户型 3D 网站

面向二次开发的两套完整前端：可编辑 JS、HTML、CSS、锁定依赖、模型/贴图和已构建网页。不是只有一个 HTML 的截图或静态导出。

- `txc/`：星宸天奕 · 奕悦，当前已发布第 7 版，含客厅唯一 360° 观察点和 6K 全景。
- `csw/`：保利 · 天奕 C119，当前已发布第 5 版。

## 直接运行

安装 Node.js 20 或更新版本。在仓库根目录执行：

```sh
npm start
```

打开 http://127.0.0.1:8080 ，选择一套户型。已提交 `dist/`，仅查看无需先安装依赖。不能直接双击 HTML：模块和模型资源需要 HTTP 服务。

## 修改并构建

```sh
npm run setup
npm run build
npm run check
npm start
```

`setup` 分别执行两套项目的 `npm ci`，需要能访问 npm 官方仓库；Three.js 固定为 0.180.0，esbuild 固定为 0.25.10。两套项目互相独立，也可以在其中一套目录执行 `npm ci`、`npm run build`、`npm run check`。

## 文件入口

- `main.js`：场景初始化、相机、天气、家具模型加载和 UI。
- `building.js`：建筑几何、墙体、门窗和程序化家具。
- `plan.js`：二维户型视图。
- `dist/index.html`、`dist/style.css`：直接编辑的页面与样式源文件。
- `dist/assets/`：运行所需模型、贴图、图纸。
- `dist/app.js`：由 esbuild 生成；改 JS 后重新构建，不要手改这个文件。
- `txc/viewpoint.js`：客厅观察点与全景弹窗。
- `txc/dist/panorama/`：自写全景查看器、6K 成图、来源说明。
- `txc/tests/viewpoint.mjs`：观察点与建筑碰撞、投影、全景文件完整性检查（非 GPU 浏览器测试）。
- `csw/layout-audit.json`：原有布置尺寸审计。

当前构建只重新生成 `dist/app.js`；**不要删除整个 dist 目录**，其中的 HTML、CSS 和素材就是当前项目源文件的一部分。

## 部署

可以将任一项目的整个 `dist/` 发布到普通静态网站托管；也可以部署整个仓库的静态内容并使用根目录入口。`npm start` 是本机开发预览服务器，不是面向公网的生产服务器。不需要密钥、登录后台、数据库或公网 CDN。

本仓库未配置自动部署。原有 Sites 的项目绑定、访问控制和线上状态不会因本仓库构建而改变。
